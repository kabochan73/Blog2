# 機能スコープ（確定版）

## 公開ページ

- [x] 記事一覧ページ
- [x] 記事詳細ページ
- [x] タグ別一覧（タグ検索）
- [x] ページネーション
- [x] 目次（TOC）自動生成
- [x] サイトマップ

**やらない**: カテゴリ分け、キーワード検索、関連記事表示、シェアボタン、ダークモード、コメント、いいね、RSSフィード

## 管理画面

- [x] ログイン/ログアウト（Sanctum、1人用）
- [x] 記事一覧ページ
- [x] 記事詳細ページ（＝プレビューを兼ねる。別途プレビュー機能は作らない）
- [x] 記事作成
- [x] 記事編集
- [x] 記事削除
- [x] タグでの絞り込み（検索）
- [x] 下書き／公開の切り替え
- [x] 画像アップロード（本文用）
- [x] サムネイル画像の設定
- [x] タグのCRUD（作成・編集・削除）と記事への付与
- [x] 画像の最適化（アップロード時にリサイズ/圧縮）

**やらない**: カテゴリ管理

## 管理者アカウント

- Laravelのdatabase seederで初期管理者を投入（username: `admin`）
- パスワード等の詳細は別途決定

## デプロイ

- 今回のスコープに含める
- Railwayへ、Dockerfileを使ってデプロイ
- backend（Laravel）・frontend（Next.js）それぞれのDockerfileを用意し、Railway上の別サービスとして動かす想定
